# Allowance Budget

## Description
Allowance Budget is a mobile application built for college students to manage their allowance by recording money in, recording money out, viewing transaction entries, and tracking their real-time balance.

## Features
- **Money In & Money Out Tracking:** Add income and expense entries with a note and amount via the entry sheet.
- **Real-Time Balance:** Automatically calculates and updates the current balance as entries are added.
- **Transaction Log (`ListView`):** Displays saved entries with indicators showing whether each transaction is Money In or Money Out.

## How to Install and Run
1. Open the project in **FlutterFlow** or launch the live run link: `https://app.flutterflow.io/run/xbc538P4V2tR1R9xldu9`
2. If opening the project source/export in FlutterFlow or Flutter:
   - Ensure Flutter SDK and dependencies are installed (`flutter pub get`).
   - Run the app in **Test / Run mode** in FlutterFlow or run `flutter run` in your terminal/IDE.
3. On the home screen, tap **Money In** or **Money Out**, enter a note and amount, and save to test the balance and list updates.
